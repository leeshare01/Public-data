PyCharm 看不到运行配置**现象**: 创建 .idea/runConfigurations 后 PyCharm 没有显示**原因**: PyCharm 启动时读取 .idea 配置，运行中修改不会自动刷新**解决**: 关闭 PyCharm 重新打开项目---### 错误 2: `ModuleNotFoundError: No module named 'pandas'`**文件**: `utils/vis.py`**解决**: `pip install pandas`---### 错误 3: `ModuleNotFoundError: No module named 'skimage'`**文件**: `utils/torchvideotransforms/video_transforms.py`**解决**: `pip install scikit-image`---### 错误 4: PyCharm 提示不满足 `mmcv==2.1.0`, `mmcv_full==1.7.2`**原因**: `requirements.txt` 中遗留的旧依赖，但代码中 `mmcv` 已注释掉 (`utils/utils.py` line 7: `#from mmcv import Config`)，实际使用的是 `mmengine`**解决**: 从 requirements.txt 中移除 mmcv/mmcv_full---### 错误 5: `RuntimeError: No CUDA GPUs are available`**文件**: `configs/train_fisv.py`**原因**: `multi_gpu = "1"` 尝试使用 GPU 1，但系统只有一张 GPU (索引为 0)**解决**: 改为 `multi_gpu = "0"`---### 错误 6: `UserWarning: lr_scheduler.step() before optimizer.step()`**文件**: `run.py` line 105-108**原因**: `scheduler.step()` 在 `optimizer.step()` 之前调用**修复**:```python# 修改前if split=="train":    scheduler.step()    optimizer.zero_grad()    loss.backward()    optimizer.step()# 修改后if split=="train":    optimizer.zero_grad()    loss.backward()    optimizer.step()    scheduler.step()```---### 错误 7: `RuntimeError: Parent directory ckpts does not exist.`**文件**: `run.py` line 120 (torch.save checkpoint)**原因**: `ckpts/` 目录不存在**解决**: `mkdir ckpts`---## 三、功能性修改### 3.1 训练结束后输出结果汇总**文件**: `run.py` line 129-131在训练循环结束后添加：```pythonlog_and_print(base_logger, f'===== Training finished! 文件 ||---|------|---------|------|| 1 | `cfg.epoch_num = 50` 硬编码覆盖，训练严重不充分 | 主要 | main.py:67 || 2 | dino_loss 噪声在测试时也生效 | 中等 | run.py:92 || 3 | 分数归一化 `/43` 硬编码，可能不匹配实际数据分布 | 中等 | dataloader_fisv.py:79 || 4 | ViViT backbone 随机初始化(无预训练) | 较小 | models/__init__.py:11 |### 修复 8: 移除 epoch 硬编码限制**文件**: `main.py` line 65-68```diff- cfg.epoch_num = 50```现在使用配置文件中的 `epoch_num = 1000`，在 epoch 400/800 各衰减 LR 一次。Fis-V 在 epoch 50 时 SRCC 还在上升(epoch 77 涨到 0.687)，提前截断是最主要原因。### 修复 9: dino_loss 噪声仅在训练时生效**文件**: `run.py` line 92```diff- if cfg.dino_loss:+ if cfg.dino_loss and split == "train":```测试时在预测值上加高斯噪声 N(0,0.05) 会压低 SRCC。### 修复 10: Fis-V 分数归一化改为动态计算**文件**: `dataloader/dataloader_fisv.py` line 24-25, 81```diff- data["score"] = self.label[clip] / 43+
