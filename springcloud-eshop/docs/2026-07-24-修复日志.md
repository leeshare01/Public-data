# 修复日志 — 2026-07-24

## 问题列表

### 阶段一：历史修复（压缩前）

#### 问题 1：订单页商品图片不显示
**现象**：购物车结算后跳转到订单页，商品图片裂了，只显示裂图占位

**根因**：前端模板用 `item.image` 取图，但后端返回的字段名是 `item.productImage`，字段名不匹配导致图片加载失败

**处理**：采纳用户建议"不用图片只留文字"，去掉所有订单页的 img 标签，改为纯文字布局展示商品名 + 规格 + 价格

#### 问题 2：多规格商品无法加入购物车
**现象**：有颜色、尺寸等选项的商品（如"蓝色，大件"），点击加购无反应

**根因**：购物车 Redis 存储按 `productId` 为 key，多规格商品的不同 SKU 互相覆盖，且没有存储规格信息（specInfo）

**处理**：购物车重构为 SKU 级别存储：
- Redis Hash `cart:{userId} → {productId: "qty,sel"}` → `cart:{userId} → {skuId: "qty,sel"}`
- `ProductDetail.vue` 选完规格后传实际 SKU ID 加购
- 首页加购兼容：传 `productId` 自动回退到该商品第一个 SKU
- 规格信息自动从 JSON（如 `{"尺寸":"S","颜色":"白色"}`）解析为可读文字（如 `"S / 白色"`）

### 阶段二：今日修复（当前会话）

#### 问题 3：普通用户无法登录（500）
**现象**：用户 "1234" 登录接口返回 500 Internal Server Error

**根因**：数据库存的 BCrypt 密码哈希与用户实际密码不匹配。管理员账号因旧 JWT token（24h 有效）仍在 localStorage 中，所以无感；但 "1234" 是新测试用户，需要重新登录，暴露了此问题。

**处理**：用正确的密码重新生成 BCrypt 哈希，更新所有用户密码。

#### 问题 4：购物车 N+1 性能瓶颈
**现象**：加购后购物车商品不出现，过一会儿才显示。用户反馈"过了一会我打开购物车突然就能出现之前缺失的商品"

**根因**：`CartService.fetchSkuMap()` 逐个遍历购物车 SKU，每个发起一次 Feign HTTP 调用：
```
for (Long skuId : skuIds) {
    ProductSkuDTO sku = fetchSku(skuId);  // 每次都是独立 HTTP 请求！
}
```
3 个商品 = 3 次 HTTP（~1-2s），5 个商品更慢。前端 `catch` 降级到 localStorage，数据在 localStorage 里能读到，所以"过一会儿出现"。
